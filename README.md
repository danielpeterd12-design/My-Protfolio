## 📖 Overview

This project is a professional portfolio application designed to present personal information, technical skills, projects, education, and achievements in an elegant and interactive interface.

Unlike a traditional portfolio, it also includes an **Analytics Dashboard** that records visitor activity, allowing portfolio owners to gain insights into user engagement and interactions.

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/your-username/resume-portfolio-viewer-analytics.git
```

```bash
cd resume-portfolio-viewer-analytics
```

---

## 📦 Install Dependencies

```bash
npm install
```

---

## ⚙️ Configure Environment Variables

Create a `.env` file from `.env.example`.

```env
# Example

PORT=3000

API_KEY=your_api_key
```

---

## ▶️ Run Development Server

```bash
npm run dev
```

Open

```
http://localhost:5173
```

---

## 🏗 Build Production Version

```bash
npm run build
```

---

## 🚀 Start Production Server

```bash
npm start
```
